# QUINTUM — с чего мы начинаем

Этот файл предназначен для человека, который не обязан быть программистом.

## Что мы строим

QUINTUM — отдельная децентрализованная сеть. Не токен в Ethereum и не запись внутри чужого блокчейна.

В будущем обычный пользователь должен:

1. скачать программу;
2. установить её;
3. запустить кошелёк;
4. автоматически найти другие узлы;
5. синхронизировать блокчейн;
6. получить адрес;
7. отправлять и принимать QUINTUM;
8. при желании участвовать в майнинге.

## Из каких частей состоит монета

**Consensus** — правила, по которым все компьютеры решают, какой блок и какая транзакция правильные.

**Blockchain** — последовательность подтверждённых блоков.

**UTXO** — учёт ещё не потраченных монет. Это модель Bitcoin.

**PoW** — майнер реально выполняет вычислительную работу, чтобы найти допустимый блок.

**P2P** — компьютеры находят друг друга и обмениваются блоками и транзакциями без центрального сервера.

**Wallet** — хранит ключи пользователя и создаёт подписанные транзакции.

## Что важно понимать

Пока mainnet не запущен, мы можем безопасно менять параметры протокола. После запуска нельзя просто поменять награду, алгоритм или genesis: старые и новые узлы перестанут считать одну и ту же цепь правильной.

Поэтому порядок работы такой:

**правила → тесты → блокчейн → P2P → майнинг → кошелёк → GUI → installer → testnet → mainnet.**

Мы не будем начинать с красивых кнопок, пока фундамент сети не доказал, что работает.
