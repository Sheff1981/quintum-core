# QUINTUM Core RandomX Testnet v0.0.3-prealpha

This release adopts **QMU** as the QUINTUM native-coin ticker before Mainnet and publishes the same desktop wallet/node UX for Windows, Linux and macOS.

## Downloads

- **Windows x64:** `QUINTUM-Core-Setup-0.0.3-prealpha-x64.exe`
- **Linux x64 (Debian/Ubuntu):** `QUINTUM-Core-0.0.3-prealpha-linux-x64.deb`
- **Linux x64 portable:** `QUINTUM-Core-0.0.3-prealpha-linux-x64.tar.gz`
- **macOS Apple Silicon:** `QUINTUM-Core-0.0.3-prealpha-macos-arm64.dmg`
- **macOS Intel:** `QUINTUM-Core-0.0.3-prealpha-macos-x64.dmg`
- macOS ZIP bundles are also published.
- `SHA256SUMS.txt` contains the checksums for all release packages.

## QMU naming

- coin name: **QUINTUM**
- ticker: **QMU**
- Mainnet candidate address HRP: `qmu`
- RandomX Testnet address HRP: `xqmu`
- Regtest HRP: `rqmu`
- the historical SHA-256 Testnet retains `tqtm` so archived test addresses/data are not reinterpreted
- the legacy `.qtmbackup` file extension is retained for backup-format compatibility

The ticker/address change does not alter RandomX PoW, ASERT, block subsidy arithmetic, founder public key, Genesis block identity, transaction IDs or existing historical SHA-256 Testnet data.

## RandomX Testnet

- PoW: RandomX v2.0.1
- target spacing: 120 seconds
- difficulty: per-block ASERT
- P2P port: 39444
- bootstrap: `212.193.15.139:39444`
- coinbase maturity: 500 blocks
- primary subsidy split: 95% miner / 5% transparent founder output
- transaction fees: 100% miner
- tail emission after the six primary eras: 1 QMU/block

## Safety

This is **pre-alpha Testnet software**. Testnet QMU has no monetary value.

Windows packages are currently unsigned. macOS packages are ad-hoc signed for bundle integrity but are not Apple Developer ID signed/notarized. Verify the GitHub Release source and `SHA256SUMS.txt` before running a build.

Never publish wallet passwords, recovery words or private keys.
