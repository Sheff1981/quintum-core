# QUINTUM Core RandomX Testnet v0.0.2-prealpha

This pre-alpha release moves public desktop testing to the isolated QUINTUM RandomX Testnet.

## Downloads

- **Windows x64:** `QUINTUM-Core-Setup-0.0.2-prealpha-x64.exe`
- **Linux x64 (Debian/Ubuntu):** `QUINTUM-Core-0.0.2-prealpha-linux-x64.deb`
- **Linux x64 portable:** `QUINTUM-Core-0.0.2-prealpha-linux-x64.tar.gz`
- **macOS Apple Silicon:** `QUINTUM-Core-0.0.2-prealpha-macos-arm64.dmg`
- **macOS Intel:** `QUINTUM-Core-0.0.2-prealpha-macos-x64.dmg`
- ZIP copies of each macOS app are also published.
- `SHA256SUMS.txt` contains release checksums.

All desktop builds use the same Qt UI/UX and default to the isolated RandomX Testnet.

## RandomX Testnet

- PoW: RandomX v2.0.1
- target spacing: 120 seconds
- difficulty: ASERT
- P2P: 39444
- bootstrap: `212.193.15.139:39444`
- separate network identity and data directory from the historical SHA-256 Testnet
- coinbase maturity: 500 blocks
- primary subsidy split: 95% miner / 5% transparent founder output
- fees: 100% miner
- tail emission after the six primary eras: 1 QMU/block

## Safety

This is pre-alpha testnet software. Testnet QMU has no monetary value.

The Windows installer is not Authenticode-signed. macOS packages are ad-hoc signed for bundle integrity but are not Apple Developer ID signed or notarized. Verify the GitHub Release source and `SHA256SUMS.txt` before running a build.

Never publish wallet passwords, recovery words or private keys.
