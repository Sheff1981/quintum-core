# QUINTUM Core Testnet v0.0.1-prealpha

This is the first public Windows pre-alpha build published for external QUINTUM Testnet testing.

## Download

For most Windows testers, download:

`QUINTUM-Core-Setup-0.0.1-prealpha-x64.exe`

Also download `SHA256SUMS.txt` and verify the installer checksum before running it.

## Important

- This is **pre-alpha testnet software**.
- There is **no QUINTUM mainnet yet**.
- Testnet QTM has **no monetary value**.
- Testnet balances are not promised to transfer to mainnet.
- This installer is currently **unsigned**. Windows may show a SmartScreen warning.
- Do not disable Windows security globally. Verify the download source and checksum.

## What to test

We are looking for real-world feedback on:

- Windows installation and updates;
- first startup and restart;
- peer discovery and automatic reconnect;
- blockchain synchronization;
- wallet creation and restore;
- receiving and sending testnet transactions;
- testnet mining and block creation;
- coinbase maturity;
- persistence after restart;
- backup and restore;
- crashes, freezes, incorrect status displays, and inconsistent balances.

Full testing guide:

https://github.com/Sheff1981/quintum-core/blob/main/docs/TESTNET_TESTING.md

## Report bugs

Open an issue:

https://github.com/Sheff1981/quintum-core/issues

Please include the Windows version, QUINTUM build/commit, steps to reproduce, expected behavior, actual behavior, and relevant logs or screenshots when safe.

Never publish recovery phrases, private keys, wallet passwords, or other secrets.
