# QUINTUM Android

QUINTUM Android is a native mobile client built around the existing C++23 QUINTUM Core. Android does not define a second consensus implementation.

## Runtime model

The target runtime is:

```
Jetpack Compose / Kotlin
        |
Android lifecycle and foreground services
        |
authenticated loopback JSON-RPC
        |
ARM64 QUINTUM C++ Core
        |
P2P / chainstate / wallet / RandomX
```

The first supported ABI is `arm64-v8a`. Additional ABIs require the same consensus and RandomX test vectors before release.

## Networking

Android participates as an outbound P2P node. Desktop UPnP/NAT-PMP port mapping is compiled out on Android; carrier and mobile NAT environments cannot be treated like desktop routers. This does not change wire protocol, peer discovery, block/transaction relay or consensus.

RPC remains bound to loopback and uses the per-run cookie generated by QUINTUM Core.

## Mining

RandomX remains the consensus implementation from the C++ Core and its pinned upstream revision. Mobile mining will be explicit, foreground, stoppable and resource-controlled. Android UI code must never simulate accepted shares, blocks or hashrate.

## Compatibility

Android work must not change Genesis, network magic, address encoding, ports, monetary policy, transaction serialization, wallet format or RandomX consensus behavior.

See `android/UPDATE_SECURITY.md` for the update contract.
