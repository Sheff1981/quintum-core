# QUINTUM Trademark and Brand Policy

This policy separates the open-source software license from the QUINTUM project's name and visual identity.

The QUINTUM Core source code is distributed under the MIT License. See [LICENSE](LICENSE).

The MIT License grants broad rights to use, copy, modify, merge, publish, distribute, sublicense and sell copies of the software, subject to its terms.

The MIT License does **not** grant trademark rights or permission to present another project, network, product or service as official QUINTUM.

## 2. QUINTUM brand identifiers

For purposes of this policy, QUINTUM brand identifiers include:

- the names **QUINTUM** and **QUINTUM Core**;
- official QUINTUM logos, symbols and icons;
- official QUINTUM visual identity and distinctive branding used to identify the project.

This policy does not state or imply that any mark is registered in any particular jurisdiction.

## 3. Uses that are generally permitted

You may use the QUINTUM name in a truthful, descriptive way to:

- refer to the QUINTUM project or QUINTUM Core software;
- link to the official repository or documentation;
- discuss, review, test, research or report on QUINTUM;
- state that your software is based on, interoperates with or is compatible with QUINTUM, provided the wording and presentation do not imply official status, sponsorship or endorsement;
- reproduce unmodified screenshots of the official software for documentation, journalism, education, testing or discussion.

These uses must not create confusion about who operates or endorses the relevant project, product, network or service.

## 4. Uses that require permission

Unless you have prior permission from the QUINTUM project, do not use QUINTUM brand identifiers:

- as the name or primary branding of a fork or modified distribution;
- as the name or branding of another coin, token, blockchain or network;
- as the name or branding of a wallet, exchange, mining service, hosted node service or other commercial product or service in a way that implies it is official;
- in a domain name, social-media account, application listing or organization name in a way likely to create confusion with the official project;
- on merchandise or promotional material in a way that implies sponsorship, partnership or endorsement;
- in altered or derivative logos presented as official QUINTUM branding.

## 5. Forks and modified versions

The MIT License permits forks and modified versions of the software.

A fork or independently operated derivative project should use its own distinct name and branding and should not present itself as an official QUINTUM release, official QUINTUM network or project endorsed by QUINTUM.

References such as "based on QUINTUM Core" are permitted when accurate and when they do not create confusion about affiliation or endorsement.

All MIT License notices required by [LICENSE](LICENSE) must still be preserved.

## 6. No endorsement

Use of QUINTUM software does not by itself create a partnership, sponsorship, affiliation or endorsement by the QUINTUM project.

## 7. Permission and questions

If a proposed use falls outside the permissions above, request permission through the official QUINTUM Core GitHub repository before using the QUINTUM brand identifiers.
